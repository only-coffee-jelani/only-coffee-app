# Only Coffee Admin Dashboard - Complete Features

## 🎯 Core Features

### 1. **Dashboard** 📊
The main hub for your business overview.

**Features:**
- Real-time metrics cards (Total Orders, Revenue, Active Users, Avg Order Value)
- Weekly orders trend chart
- Weekly revenue bar chart
- Quick action buttons for common tasks
- Responsive grid layout
- Color-coded statistics

**Use Cases:**
- Monitor daily business performance
- Track revenue trends
- Identify peak sales periods
- Quick access to management tools

---

### 2. **Splash Screen Manager** 🎬
Control the launch modal that appears when users open the app.

**Features:**
- Upload custom splash screen image from S3
- Edit title and description
- Set display duration (1-30 seconds)
- Configure active date range
- Toggle active/inactive status
- Real-time preview with countdown
- Automatic image caching

**Use Cases:**
- Launch new promotions
- Announce special offers
- Seasonal campaigns
- Product launches

---

### 3. **Carousel Manager** 🎠
Manage up to 5 promotional images on the home screen.

**Features:**
- Upload up to 5 promotional images
- Edit image titles
- Drag-and-drop interface
- Real-time carousel preview
- Navigation between images
- Auto-scroll simulation
- Image position indicators
- Batch management

**Use Cases:**
- Rotate promotional content
- Feature different products
- Seasonal promotions
- Limited-time offers

---

### 4. **Menu Items Manager** 🍰
Create and manage all products available in your stores.

**Features:**
- Create new menu items with full details
- Edit existing items
- Delete items
- Set pricing and descriptions
- Upload product images
- Categorize items (Coffee, Tea, Pastry, Sandwich)
- Select which stores carry each item
- Multi-store availability
- Search and filter capabilities

**Use Cases:**
- Add new products
- Update pricing
- Manage inventory
- Control store-specific menus
- Seasonal menu changes

---

### 5. **Images Manager** 🖼️
Centralized management of all S3 bucket images.

**Features:**
- View all uploaded images in grid layout
- Filter by type (Splash, Carousel, Menu Items, Stores)
- Copy image URLs to clipboard
- Download images
- Delete unused images
- Image metadata display
- Upload date tracking
- File size information

**Use Cases:**
- Organize media assets
- Reuse existing images
- Clean up unused files
- Quick URL access for developers

---

### 6. **Stores Manager** 🏪
Manage all Only Coffee store locations.

**Features:**
- Add new store locations
- Edit store information
- Delete stores
- Upload store images
- Store address and contact info
- Phone and email management
- Active/inactive status toggle
- Store-specific menu management
- Location-based operations

**Use Cases:**
- Add new locations
- Update store information
- Manage store hours
- Track store status
- Location-specific promotions

---

### 7. **Analytics Dashboard** 📈
Comprehensive business intelligence and reporting.

**Features:**
- Key metrics overview (Orders, Revenue, AOV, Satisfaction)
- Orders & Revenue trend lines
- Sales by category pie chart
- Top-selling items table
- Date range filtering (Week, Month, Year)
- Export data functionality
- Performance trends
- Category breakdown

**Use Cases:**
- Analyze sales performance
- Identify top products
- Track revenue trends
- Make data-driven decisions
- Generate reports

---

### 8. **Settings Page** ⚙️
Manage admin account and application settings.

**Features:**
- Company information management
- Email and phone settings
- Website URL configuration
- Timezone selection
- Notification preferences (Email, SMS, Push)
- Maintenance mode toggle
- Password change functionality
- Security settings

**Use Cases:**
- Update company details
- Configure notifications
- Manage admin account
- System maintenance
- Security management

---

### 9. **Authentication System** 🔐
Secure admin access with JWT tokens.

**Features:**
- Email/password login
- JWT token management
- Secure token storage
- Auto-logout on token expiry
- Remember me functionality
- Password recovery link
- Demo credentials for testing
- Role-based access control

**Use Cases:**
- Secure admin access
- Multi-user support
- Account management
- Session management

## 🔄 Workflow Examples

### Adding a New Product
1. Go to Menu Items Manager
2. Click "Add Menu Item"
3. Fill in product details
4. Upload product image
5. Select stores
6. Save

### Launching a Promotion
1. Go to Splash Screen Manager
2. Upload promotional image
3. Set title and description
4. Configure display duration
5. Set active dates
6. Save and publish

### Analyzing Sales
1. Go to Analytics
2. Select date range
3. View key metrics
4. Check top-selling items
5. Export report
