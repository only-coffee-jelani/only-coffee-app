# ⚡ Quick Start Guide - Only Coffee Admin Dashboard

## 🚀 Get Running in 3 Minutes

### Step 1: Install (30 seconds)
```bash
cd admin
npm install
```

### Step 2: Start (10 seconds)
```bash
npm run dev
```

### Step 3: Login (20 seconds)
Open http://localhost:5173 and login with:
- **Email**: admin@onlycoffee.us
- **Password**: demo123

**Done! 🎉**

---

## 📱 What You Can Do Now

### 1. Update Splash Screen
1. Click "Splash Screen" in sidebar
2. Upload a new image
3. Set title and duration
4. Click "Save Changes"
5. ✅ Changes appear in app instantly!

### 2. Manage Carousel
1. Click "Carousel" in sidebar
2. Upload up to 5 promotional images
3. Reorder or remove images
4. Click "Save Carousel"
5. ✅ Carousel updates in app!

### 3. Add Menu Items
1. Click "Menu Items" in sidebar
2. Click "Add Menu Item"
3. Fill in details (name, price, description)
4. Upload product image
5. Select which stores carry it
6. Click "Save Item"
7. ✅ Product appears in app!

### 4. Manage Stores
1. Click "Stores" in sidebar
2. Click "Add Store"
3. Enter store details
4. Upload store image
5. Click "Save Store"
6. ✅ Store appears in app!

### 5. View Analytics
1. Click "Analytics" in sidebar
2. See sales trends and metrics
3. Check top-selling items
4. Export data if needed

## 🆘 Troubleshooting

### Can't Login?
- Check email and password
- Ensure backend is running
- Clear browser cache

### Images Won't Upload?
- Check file size (max 5MB)
- Verify file format (JPG, PNG, WebP)
- Check S3 bucket permissions

### Changes Not Appearing?
- Refresh the app
- Check backend is running
- Verify API connection
