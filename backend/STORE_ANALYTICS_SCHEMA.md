# Store Analytics Schema Documentation

## Overview
The enhanced `stores` table now includes comprehensive tracking for analytics, sales, reporting, and operational metrics. This document outlines all the new columns and their purposes.

## Column Categories

### 1. Sales & Revenue Tracking
Track financial performance of each store.

| Column | Type | Default | Description |
|--------|------|---------|-------------|
| `total_orders` | int | 0 | Total number of orders placed at this store |
| `total_revenue` | decimal(12,2) | 0 | Total revenue generated by this store |
| `total_revenue_today` | decimal(12,2) | 0 | Revenue for today |
| `total_revenue_this_week` | decimal(12,2) | 0 | Revenue for this week |
| `total_revenue_this_month` | decimal(12,2) | 0 | Revenue for this month |
| `average_order_value` | decimal(10,2) | 0 | Average value per order |
| `highest_order_value` | decimal(10,2) | 0 | Highest single order value |

## Relations

### Many-to-Many: Store ↔ MenuItem
Stores have a many-to-many relationship with menu items through the `store_menu_items` junction table.

```typescript
@ManyToMany(() => MenuItem, (menuItem) => menuItem.stores)
@JoinTable({
  name: 'store_menu_items',
  joinColumn: { name: 'store_id', referencedColumnName: 'id' },
  inverseJoinColumn: { name: 'menu_item_id', referencedColumnName: 'id' },
})
menuItems: MenuItem[];
```

This allows:
- Each store to have multiple menu items
- Each menu item to be available at multiple stores
- Tracking which items are available at which locations

## Indexes Created

For optimal query performance, the following indexes are created:

- `idx_stores_total_revenue` - For revenue-based sorting and filtering
- `idx_stores_total_orders` - For order-based sorting and filtering
- `idx_stores_is_open_now` - For finding open stores
- `idx_stores_average_rating` - For rating-based sorting
- `idx_stores_is_active` - For filtering active stores
- `idx_stores_created_at` - For date-based sorting

## Usage Examples

### Get top-performing stores by revenue
```sql
SELECT name, total_revenue, total_orders, average_order_value
FROM stores
ORDER BY total_revenue DESC
LIMIT 10;
```

### Get stores with low inventory
```sql
SELECT name, low_stock_items_count, out_of_stock_items_count
FROM stores
WHERE low_stock_items_count > 0 OR out_of_stock_items_count > 0;
```

### Get stores with high customer satisfaction
```sql
SELECT name, customer_satisfaction_score, averageRating, totalReviews
FROM stores
WHERE customer_satisfaction_score >= 4.5
ORDER BY customer_satisfaction_score DESC;
```

### Get profitability analysis
```sql
SELECT 
  name,
  total_revenue,
  cost_of_goods_sold,
  gross_profit,
  gross_profit_margin,
  net_profit,
  net_profit_margin
FROM stores
ORDER BY net_profit DESC;
```
